# Dubbing Studio 用户使用手册

**版本：BETA**  
**适用对象：**需要把视频对白翻译、重新配音并保留背景音乐或环境声的创作者、剪辑人员和研发测试人员。

Dubbing Studio 是一个基于时间轴的网页配音工作台。它把视频预览、对白文本、角色分配、音频波形、时间轴对齐、背景混音、声音试听和版本保存放在同一个编辑界面中。

> 本手册描述当前仓库中的实际功能。真实的克隆语音合成和最终视频导出依赖单独部署的处理节点；未配置处理节点时，界面仍可用于本地视频预览、对白编辑、时间轴调整和版本操作，但不能完成真实的语音合成或导出。

## 1. 开始前的准备

使用完整工作流前，需要满足以下条件：

1. 能够访问 Dubbing Studio 网页。
2. 已完成登录。上传、项目创建、版本保存、版本回退和处理节点代理接口均需要服务端登录态。
3. 准备好一个可读取的视频文件。浏览器端会用它生成本地预览和波形；登录后，文件还会以分片方式上传到服务端存储。
4. 如果需要真实声音克隆试听或最终导出，管理员必须在服务端配置 `PROCESSING_NODE_URL` 和 `PROCESSING_NODE_TOKEN`，并保证处理节点可以访问源视频或相关存储地址。

建议先准备一段较短的视频进行测试。确认上传、试听和导出链路正常后，再处理大文件或长视频。

## 2. 登录与工作台布局

打开应用后，页面顶部显示 Dubbing Studio 标识、处理节点状态、当前用户和“保存版本”按钮。页面主体分为三个区域：

- **左侧项目区：**显示当前视频、导入新视频入口、编辑历史和处理节点状态。
- **中间工作区：**显示视频预览、时间轴、音频波形和字幕/混音/克隆面板。
- **右侧片段编辑区：**编辑当前选中的对白片段的时间、原文、译文、角色和片段音量。

当前页面采用深色主题。浏览器窗口较窄时，左侧项目区会隐藏，主要编辑区仍可使用；建议在桌面浏览器中进行精细时间轴编辑。

## 3. 导入视频并创建项目

### 3.1 选择视频

可以通过以下任一入口选择视频：

- 左侧“导入新视频”；
- 页面顶部“替换视频”；
- 左侧项目区右上角的加号按钮。

选择文件后，应用会立即建立浏览器本地预览，并尝试读取音频时长和波形。登录状态下，应用随后会自动创建上传会话，将视频切成 **8 MiB** 分片并逐片上传。上传完成后，服务端自动创建项目。

### 3.2 查看上传进度

上传期间会显示进度条和两个操作：

- **暂停上传：**暂停发送后续分片，已经完成的分片不会丢失。
- **继续上传：**从暂停位置继续。
- **取消上传：**删除当前上传会话，并清除浏览器保存的该文件续传标识。

应用会用“文件名、文件大小和最后修改时间”生成本地续传键。浏览器刷新后再次选择同一个文件时，应用会尝试读取已有会话并跳过已完成分片。若会话已过期或服务端返回失败，应用会重新建立会话。

### 3.3 上传失败时的处理

看到“上传失败”提示时，可以重新选择文件。当前版本保留同一会话中已经完成的分片，但如果服务端会话已被删除或不可访问，则需要重新上传。

上传成功后，左侧项目状态会从“本地草稿”变为“已创建项目”。只有已创建项目才可以把版本快照写入服务端，也只有已创建项目才能稳定地调用处理节点任务。

## 4. 视频预览与波形

视频预览区域支持播放和暂停。播放头会随视频时间更新，并在时间轴上显示当前位置。上传视频后，浏览器会使用本地对象地址预览，因此本地预览不等于处理节点已经完成视频处理。

波形由浏览器读取视频中的音频数据后计算得到。它用于帮助定位对白和环境声，不是处理节点分离后的 `vocals` 或 `no_vocals` 音轨。最终的人声分离和混音仍由外部处理节点完成。

## 5. 编辑对白和译文

选择“字幕与配音”面板后，可以看到对白片段列表。每行包含：

- 片段编号；
- 起止时间；
- 原文；
- 译文；
- 角色；
- 单句试听按钮。

点击某一行后，右侧“片段编辑”区域会切换到该片段。常用编辑步骤如下：

1. 在“原文”输入框中修正识别结果。
2. 在“译文”输入框中改写目标语言，使表达自然并适合口播。
3. 选择正确的角色。
4. 修改开始和结束时间，或直接在时间轴上拖动片段。
5. 用片段音量滑块调整该句相对音量。
6. 点击“保存版本”保留当前状态。

编辑原文、译文、角色、时间或音量时，应用会把修改加入本地编辑历史，并将当前状态标记为未保存。

### 5.1 添加片段

在“对白时间轴”卡片中点击“添加片段”可以创建新的编辑历史记录。当前版本的主要持久化模型围绕已上传项目和已有片段设计；添加后请检查右侧编辑器和时间轴上的内容，并在需要时保存远程版本。

### 5.2 调整时间

可以用两种方式调整片段时间：

- 在右侧直接编辑“开始 (ms)”和“结束 (ms)”；
- 在时间轴上拖动片段整体移动，或拖动片段左、右边缘分别调整入点和出点。

时间单位是毫秒。应用会限制开始时间不小于 0，并保证片段保留至少约 200 毫秒的长度。相邻片段不会自动吸附或自动重新分配空隙，因此精细对齐后应再次播放视频检查口型和节奏。

## 6. 时间轴缩放与精细对齐

时间轴右上角的“缩放”滑块范围为 **0.5× 到 4×**：

- 小于 1×：显示更长的时间范围，适合查看整体结构；
- 1×：默认视图；
- 大于 1×：显示更短的时间范围，适合精细调整。

缩放改变的是可视时间范围，不会改变片段实际的毫秒时间。调整后，仍应以右侧开始/结束字段和视频播放结果为准。

## 7. 角色分配和单句试听

当前界面内置以下示例角色和预置音色映射：

- 旁白：温和叙述音；
- Peppa：明亮儿童音；
- 猪妈妈：温柔女声；
- 猪爸爸：亲切男声。

在每个片段的角色列中点击试听按钮，可以为该句生成目标语言音频。试听流程如下：

1. 应用先检查浏览器的本地音频缓存。
2. 如果命中缓存，直接播放，不重复等待合成。
3. 如果没有缓存，应用通过服务端代理把任务提交到处理节点。
4. 页面显示任务进度和“取消试听”按钮。
5. 任务完成后，浏览器播放返回音频，并把结果写入 Cache Storage。

试听缓存键包含项目、片段、译文、角色和片段音量。修改译文、角色或音量后会生成新的缓存键，不会错误复用旧音频。

> 声音克隆不是在浏览器中完成的。Dubbing Studio 不会把 `PROCESSING_NODE_TOKEN` 发送给浏览器；服务端验证用户后，再向外部处理节点转发任务。

### 7.1 未配置处理节点时

如果处理节点地址为空、令牌错误或节点不可访问，试听会显示明确错误。此时不要把浏览器缓存、视频本地预览或“Ready”字样理解为克隆任务已经可用；应先让管理员检查处理节点配置和健康状态。

### 7.2 声音克隆设置面板

“声音克隆”面板用于说明真实处理节点试听和参考音频工作流。当前界面的“上传参考音频”和“提取角色样本”入口属于后续接入点，真正的参考音频上传与角色样本提取能力需要继续绑定处理节点接口后才能使用。

## 8. 背景混音

选择“背景混音”面板后，可以调整两个全局参数：

- **背景音乐与环境声：**控制分离后的背景层增益，默认 82%；
- **普通话配音：**控制新配音层增益，默认 100%。

当前工作流采用“保留 `no_vocals` 层，再按对白窗口做动态衰减”的策略。它的目标是保留音乐和环境声，同时降低原对白对新配音的干扰。最终分离、动态衰减和混音由处理节点执行，浏览器中的滑块只是向导出任务传递参数。

建议先使用默认值试听，再逐步调整：

- 背景声盖住译文时，降低背景音量或提高配音音量；
- 配音过于突出时，降低配音音量；
- 音乐在对白之间仍需保留时，不要把背景音量直接设为 0%。

## 9. 保存版本与回退

### 9.1 保存当前版本

点击页面顶部“保存版本”会：

1. 把当前片段状态加入浏览器本地历史；
2. 如果项目已经创建，则把快照写入服务端版本表；
3. 刷新远程版本列表；
4. 将页面状态标记为已保存。

版本快照包含片段的时间、角色、原文、译文、预置音色字段和片段音量。视频文件本身不会被复制到每个版本中。

### 9.2 查看历史

点击左侧“编辑历史”可以打开历史入口。历史记录分为两类：

- **本地编辑历史：**保存最近的编辑动作，用于回到浏览器当前会话中的状态；
- **远程版本：**由“保存版本”写入服务端，可以在刷新页面或换设备后继续使用，前提是登录到同一账户并访问同一项目。

### 9.3 回退版本

回退前建议先保存当前状态。选择远程版本并执行回退后，应用会：

- 先在本地保存一次回退前状态；
- 请求服务端恢复选定版本；
- 用服务端返回的片段重新填充当前编辑器；
- 刷新远程版本列表；
- 将当前编辑器标记为已同步。

回退只改变项目的对白编辑状态，不会删除原始上传文件，也不会自动撤销已经提交到处理节点的任务。

## 10. 最终导出

完整导出需要满足两个条件：

- 已上传视频并创建项目；
- 已配置可用的处理节点。

导出任务会把源视频地址、背景增益、配音增益和所有片段时间/角色/文本发送给服务端代理，再由处理节点完成：

1. 提取或读取音频；
2. 分离人声与背景；
3. 合成目标语言语音；
4. 按时间轴对齐片段；
5. 混合背景声和新配音；
6. 将新音轨与原视频重新封装。

页面会显示导出进度。任务完成后会出现视频下载地址。导出任务进行中可以点击取消；取消只针对当前处理任务，不会删除项目或版本。

> 页面上的“开始处理”按钮是工作流入口样式。具体导出提交使用当前版本中的处理任务接口；如果部署版本没有把该按钮绑定到导出动作，请在导出区域或后端 API 中调用对应任务接口。

## 11. 推荐工作流

建议按以下顺序操作：

1. 登录并导入短视频测试上传。
2. 检查视频预览、时长和波形。
3. 修正原文和译文，避免先合成后大规模返工。
4. 分配角色并调整每句时间。
5. 为关键片段试听，确认处理节点和音色可用。
6. 调整背景声和配音增益。
7. 保存一个明确命名的版本。
8. 提交最终导出。
9. 播放导出视频，检查对白清晰度、环境声连续性、片段边界和音画同步。
10. 如需修改，回到上一个版本或继续编辑后再次保存和导出。

## 12. 常见问题

### 页面能打开，但点击上传没有创建项目

先确认已经登录。匿名用户可以看到部分页面结构，但受保护的上传和项目接口会拒绝请求。然后检查浏览器开发者工具中的网络请求是否返回 401 或 403。

### 上传到一半关闭了浏览器，能否继续

重新打开页面并选择同一个文件。应用会尝试从浏览器本地存储恢复上传会话。如果服务端会话仍有效，会跳过已完成分片；如果会话失效，需要重新上传。

### 单句试听一直失败

依次检查登录态、`PROCESSING_NODE_URL`、`PROCESSING_NODE_TOKEN`、处理节点健康状态以及处理节点是否能访问音频或模型文件。若节点返回失败状态，优先查看处理节点日志，而不是重复点击试听。

### 为什么导出视频没有背景音乐

确认背景增益没有设置为 0，并检查处理节点是否实际运行了人声分离和混音步骤。浏览器波形只用于编辑，不能证明 `no_vocals` 音轨已经生成。

### 为什么修改后回退了，但旧的试听音频仍在播放

停止当前试听后再重新播放。修改译文、角色或音量会生成新的缓存键；旧音频仍可能保留在浏览器缓存中，但不会被新的参数自动复用。

### 公开仓库是否包含我的视频或声音样本

不包含。仓库只保存源代码和文档。上传视频、生成音频、导出视频、模型和运行时令牌应存放在部署环境或对象存储中，不能提交到 Git。

## 13. 当前版本边界

以下能力需要外部服务或后续接入，不能仅靠浏览器完成：

- 真实 GPT-SoVITS/OpenVoice 声音合成；
- 参考音频上传和角色样本提取；
- Demucs 或其他模型的人声分离；
- 最终视频混音和封装；
- 多格式、多码率和硬字幕导出；
- 实时 WebSocket/SSE 任务推送。

处理节点的部署和 API 约定请参阅 [GPT-SoVITS Processing Node API 文档](https://github.com/hibobo/gpt-sovits-processing-node/blob/main/docs/API.md)。
